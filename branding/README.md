# Identité de l'établissement

Placez ici le logo de **votre** établissement (PNG, JPG ou SVG, de préférence sur fond
transparent ou blanc, plutôt large que haut) et indiquez son chemin dans `config.json` :

```json
"logo": "branding/logo.png"
```

Si le fichier est absent, un logo par défaut est affiché (`static/logo-default.svg`).
Le logo et `config.json` sont propres à chaque établissement : ils ne sont pas versionnés.
