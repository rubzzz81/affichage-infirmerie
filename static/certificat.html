Certificat de sécurité

À quoi ça sert ?

Les pages de connexion de l'infirmerie sont chiffrées (HTTPS) pour protéger votre code. Votre appareil doit connaître l'autorité de certification du lycée ; sans cela, le navigateur affiche « connexion non sécurisée ». À faire une seule fois par appareil.

Télécharger le certificat

Avant de l'installer, vérifiez l'empreinte (SHA-256). Elle doit être identique à celle que vous a communiquée la personne qui administre le Pi :

chargement…

Si l'empreinte est différente, n'installez pas le fichier.

Installation

Windows (PC)
  1. Ouvrir le fichier téléchargé, puis Installer le certificat…
  2. Choisir Utilisateur actuel, puis Placer tous les certificats dans le magasin suivant → Parcourir → Autorités de certification racines de confiance.
  3. Valider, puis redémarrer le navigateur. (Firefox : Paramètres → Vie privée et sécurité → Certificats → Afficher les certificats → Autorités → Importer.)
Android
  1. Ouvrir Paramètres → Sécurité (ou Sécurité et confidentialité) → Chiffrement et identifiants → Installer un certificat → Certificat d'autorité de certification.
  2. Confirmer l'avertissement et choisir le fichier téléchargé.
iPhone / iPad
  1. Ouvrir le fichier téléchargé et autoriser le téléchargement du profil.
  2. Réglages → Profil téléchargé → Installer.
  3. Réglages → Général → Informations → Réglages des certificats : activer la confiance pour ce certificat.
Mac
  1. Ouvrir le fichier : Trousseau d'accès s'ouvre ; l'ajouter au trousseau « Session ».
  2. Double-cliquer sur le certificat → Confiance → Toujours approuver.

Ce certificat ne sert qu'à identifier le serveur de l'infirmerie. Il ne donne aucun accès.
